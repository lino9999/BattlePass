# BattlePass release notes

## 8.6.1 — Missions & Stability Update

This update brings together the latest compatibility work and the fixes made since the previous 8.6 download.

- Supports Minecraft Java 1.21.11–26.3 on Spigot and available Paper releases, including the blocks available in each server version.
- More reliable mission recognition for golden apples, enchanted golden apples, dirt and other block names entered through the mission editor.
- More accurate progress for crafting, villager trades, movement, play time and combat.
- Improved XP boosts, daily rewards, reward claims and Battle Coin deliveries.
- Better protection for player progress during restarts, reloads and mission or season resets.
- More reliable season countdowns, reward rotation, menus, leaderboards and placeholders.
- Improved item rewards, translated text and visual feedback.
- Internal cleanup makes future updates easier while preserving existing gameplay.

Use Java 21 for Minecraft 1.21.11 and Java 25 for 26.x. Paper does not publish a 26.1 release build; its 26.1.1 build is alpha. See the [compatibility guide](COMPATIBILITY.md) for exact versions and checks.

To update, stop the server, back up your BattlePass folder and database, replace the old plugin JAR and restart. Keep your existing configuration and player data.
